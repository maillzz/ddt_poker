# Poker Monte Carlo

Сервис поддержки принятия решений в Texas Hold'em
на основе метода Монте-Карло.

## Идея

Пользователь передаёт состояние текущей покерной раздачи:

- две карты игрока;
- количество противников;
- открытые карты стола;
- параметры текущей ставки.

Сервис моделирует большое количество возможных продолжений
раздачи и оценивает:

- вероятность победы;
- вероятность ничьей;
- вероятность поражения.

На основании заданной стратегии сервис формирует рекомендацию:

- RAISE — повысить ставку;
- CALL — продолжить с текущей ставкой;
- FOLD — сбросить карты.

## Как работает

Текущее состояние раздачи
        ↓
Генерация случайных вариантов
        ↓
Моделирование большого количества раздач
        ↓
Определение победителя каждой раздачи
        ↓
Расчёт статистики
        ↓
Рекомендация игроку

## Texas Hold'em

Раздача проходит по этапам:

1. Preflop — игрок получает две карты.
2. Flop — открываются три карты стола.
3. Turn — открывается четвёртая карта.
4. River — открывается пятая карта.

После каждого этапа вероятность победы может быть пересчитана.

## Основная технология

Метод Монте-Карло используется для приближённой оценки
вероятности победы на основе большого количества случайных
симуляций.

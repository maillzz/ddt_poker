# ADR-001. Выбор стека: Django + Django Ninja

Статус: принято
Дата: 2026-09-03

## Контекст

Наша команда из нескольких студентов разрабатывает сервис Poker Monte Carlo
для оценки вероятностей победы, ничьей и поражения в Texas Hold'em.
Команда имеет разный уровень опыта в Python и веб-разработке, поэтому нам
важно сократить количество инфраструктурного кода и сосредоточиться на
реализации покерного вычислительного ядра. Нам также необходимы веб-интерфейс,
REST API, хранение задач и возможность дальнейшего добавления очереди
для долгих Monte Carlo симуляций.

## Рассмотренные варианты

1. Django + Django Ninja — предоставляет ORM, админку, формы и REST API.
2. FastAPI — проще для API, но дополнительные части инфраструктуры придётся
   собирать самостоятельно.
3. Flask — минималистичный вариант, но требует ещё больше ручной настройки.

## Решение

Используем Django + Django Ninja, сохраняя вычислительное ядро отдельно
от веб-слоя.

## Последствия

Мы быстрее получаем рабочий веб-сервис и API, но должны соблюдать структуру
Django и разделение слоёв проекта.

# Poker Lab: фронтенд

## Что изменено

Интерфейс интегрирован в существующий Django-проект без React, npm-сборки и новых зависимостей.

- `templates/base.html`: общий каркас, навигация, выход через POST с CSRF.
- `templates/web/form.html`: калькулятор, параметры, ручной ввод и выбор карт.
- `templates/web/table.html`: общий визуальный стол формы и результата.
- `templates/web/detail.html`: проценты Win/Tie/Loss, эквити, рекомендация, ожидание и ошибка.
- `templates/web/list.html`: история задач текущего пользователя и пустое состояние.
- `templates/registration/login.html`: вход.
- `web/static/poker/app.css`: адаптивные стили, фокус клавиатуры, reduced motion.
- `web/static/poker/app.js`: выбор из 52 карт, блокировка повторов, пресеты и опрос API с повтором при обрыве связи.
- `web/templatetags/poker_display.py`: преобразование долей из ядра в проценты для отображения.

Ядро, схема БД, API и сервисный слой не изменены. Все данные формы по-прежнему валидируются сервером. Стандартный текстовый ввод доступен без JavaScript.

## Установка изменений в свой checkout

Распакуйте `frontend-overlay.zip` **в корень существующего `ddt_poker`**, согласившись на замену файлов. Архив содержит только новые и изменённые файлы; `.env`, БД и пользовательские данные в него не входят. Сначала сохраните свои незакоммиченные изменения.

Далее используйте обычный запуск проекта:

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Если запускаете впервые, создайте `.env` по `.env.example`, задайте случайный `SECRET_KEY`, установите `DEBUG=1` для локальной разработки, затем создайте аккаунт:

```bash
python manage.py createsuperuser
```

Откройте `http://127.0.0.1:8000/accounts/login/`, затем раздел «Калькулятор» (`/tasks/new/`).

Для production используйте `python manage.py collectstatic --noinput` и настройте раздачу `STATIC_ROOT` веб-сервером. Django runserver автоматически отдаёт статику только при `DEBUG=1`.

Альтернатива архиву — `git apply frontend.patch` в корне исходной версии репозитория.

## Ассеты и лицензии

Локальная колода состоит из 52 новых SVG-карт, SVG-рубашки, знака и фишек. Эти SVG созданы специально для проекта; внешние шрифты, CDN и изображения не требуются. Сохраняется формат карт ядра: `As`, `Kh`, `Td` и т. п.

На столе используются две PNG-фишки Kenney Board Game Pack. Также добавлены два необязательных звука для будущего расширения; автоматически они не воспроизводятся.

- Источник: https://kenney.nl/assets/boardgame-pack
- Автор: Kenney (https://kenney.nl)
- Лицензия: CC0 1.0. Исходный текст сохранён в `web/static/poker/kenney/license.txt`.
- Добавлены: `chipGreenWhite.png`, `chipWhiteBlue.png`, `cardPlace1.ogg`, `chipsCollide1.ogg`.
- Дополнительный набор карт: https://kenney.nl/assets/playing-cards-pack (CC0, пиксельный стиль; не используется текущим интерфейсом).

## Границы модели

UI показывает результат существующего ядра, а не полноценную GTO-стратегию. Соперники получают случайные руки; модель не учитывает их диапазоны, стиль игры и будущие ставки. Формулу equity и рекомендации фронтенд не изменяет. Неизвестные карты остаются пустыми. Текстовый ввод сохраняет поддержку 0–5 общих карт по текущей схеме проекта.

# Poker Lab assets

## Original SVG assets

`cards/*.svg`, `mark.svg`, and `chips.svg` were created for this project.
These original SVG assets are dedicated to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

The 52 faces use the same rank/suit codes as the solver. `back.svg` is an optional card back.

## Kenney assets

Source: Kenney Board Game Pack, https://kenney.nl/assets/boardgame-pack
Author: Kenney, https://kenney.nl
License: CC0 1.0, original notice in `kenney/license.txt`.

Included unchanged: `chipGreenWhite.png`, `chipWhiteBlue.png`,
`cardPlace1.ogg`, `chipsCollide1.ogg`.

The two chip images are used on the table. The two sounds are optional and are not played by the interface.
